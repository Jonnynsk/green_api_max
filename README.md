# MAX Chat Web Client (GREEN-API)

Web-клиент для отправки и получения текстовых сообщений в мессенджере MAX через GREEN-API.

## Требования

- Node.js 18+
- npm 9+
- Аккаунт GREEN-API с созданным инстансом MAX

## Установка

```bash
# Клонирование репозитория
git clone <repository-url>
cd green

# Установка зависимостей
npm install
```

## Запуск

### Режим разработки
```bash
npm run dev
```
Приложение будет доступно по адресу: `http://localhost:3000`

### Продакшн сборка
```bash
npm run build
```
Собранные файлы будут в папке `dist/`

### Превью продакшн сборки
```bash
npm run preview
```

## Настройка GREEN-API

1. Зарегистрируйтесь на [GREEN-API](https://console.green-api.com/)
2. Создайте новый инстанс типа **MAX**
3. Авторизуйте инстанс через QR-код в приложении MAX
4. Включите настройку **"Получать уведомления о входящих сообщениях и файлах"** в настройках инстанса
3. Скопируйте `idInstance` и `apiTokenInstance`

## Использование

1. Откройте приложение в браузере (`http://localhost:3000`)
2. При первом запуске откроется модальное окно настройки
4. Введите `idInstance` и `apiTokenInstance` из кабинета GREEN-API
5. Нажмите **"Войти"**
6. После успешной авторизации откроется интерфейс чата
7. Нажмите `+` в левой панели для создания нового чата
5. Введите номер телефона получателя (например: `79001234567`)
6. Начните переписку
